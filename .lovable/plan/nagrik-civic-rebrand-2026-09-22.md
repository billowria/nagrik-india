# Nagrik civic rebrand

## Goal

Rebrand the existing synchronized requester and marshal prototype from TrafficMitra to Nagrik using the supplied Civic Shield & Beacon logo, while broadening requests beyond roadside assistance.

## Changes

- Add the supplied Nagrik logo to visible brand locations and derive the browser icon from it.
- Update product naming, safety messaging, requester language, and marshal language to reflect civic assistance.
- Replace road-only issue choices with broader civic categories while preserving the existing request and mission lifecycle.
- Update demo content, history examples, page metadata, and accessible labels so the experience consistently says Nagrik.
- Preserve the current mobile/tablet layouts, shared local state, deep links, and working interactions.

## Verification

- Check requester issue selection and marshal request handling on phone and tablet widths.
- Confirm the logo, browser icon, metadata, and Nagrik wording appear without clipping or stale TrafficMitra branding.
